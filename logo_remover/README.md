# 🧹 Logo Remover — أداة إزالة اللوغو من الفيديو

عدّة عملية لإزالة أي لوغو / علامة مائية من الفيديو، بمسارين حسب صعوبة الحالة:

| المسار | مناسب لـ | السرعة | يحتاج GPU؟ |
|---|---|---|---|
| **`delogo`** (ffmpeg) | لوغو **ثابت** فوق خلفية بسيطة (سما، تدرّج لوني) | سريع جدًا ⚡ | لا |
| **`propainter`** (ذكاء صناعي) | خلفية **معقّدة** أو لوغو **متحرك** — بيمنع الرعشة | أبطأ | يُفضّل |

الفكرة اللي وراها: بدل ما تشيل اللوغو من كل فريم لوحده (اللي بيسبّب "رعشة"
لأن كل فريم بيتملّى باجتهاد مختلف)، `ProPainter` بيراعي **الفريمات المجاورة**
وبينقل تفاصيل حقيقية من فريم لفريم → نتيجة ثابتة ومقنعة.

---

## 1) التثبيت

```bash
# أدوات الماسك
pip install -r logo_remover/requirements.txt

# ffmpeg (لمسار delogo ولإرجاع الصوت)
#   Ubuntu/Debian:  sudo apt-get install -y ffmpeg
#   macOS (brew):   brew install ffmpeg
#   Windows:        نزّله من ffmpeg.org وضِفه للـ PATH
```

لمسار الذكاء الصناعي:

```bash
bash logo_remover/setup_propainter.sh
```

---

## 2) الخطوات

### المفهوم: الماسك (mask)
الماسك صورة أبيض/أسود بنفس مقاس الفيديو:
- **أبيض** = مكان اللوغو (هيتشال).
- **أسود** = الباقي (يفضل زي ما هو).

انت اللي بتحدّد شكل/مكان اللوغو مرة واحدة، والماسك ده بيتطبّق على كل الفريمات.

### أ) إنشاء الماسك

**بالرسم اليدوي** (محليًا، بتفتح أول فريم وترسم مستطيل حوالين اللوغو):
```bash
python logo_remover/make_mask.py --video in.mp4 --draw --out mask.png
# داخل النافذة:  اسحب لرسم مستطيل | z=تراجع | s=حفظ | q=خروج
```

**أو بإحداثيات مربع** (لو عارفها):
```bash
python logo_remover/make_mask.py --video in.mp4 --box 25,62,232,110 --out mask.png
```

### ب) الإزالة

**سريعة (لوغو ثابت / خلفية بسيطة):**
```bash
python logo_remover/remove_logo.py --mode delogo \
    --video in.mp4 --box 25,62,232,110 --out out.mp4
```

**بالذكاء الصناعي (خلفية معقّدة):**
```bash
python logo_remover/remove_logo.py --mode propainter \
    --video in.mp4 --mask mask.png --out out.mp4 --fp16
```
> الصوت الأصلي بيترجع تلقائيًا (ProPainter بيشيله أثناء المعالجة).
> لو الذاكرة قليلة زوّد `--resize_ratio 0.5`.

---

## 3) لو اللوغو **بيتحرك**؟

الماسك الثابت مش هيكفي. عندك حلّان:

1. **ماسك متحرك**: بدل صورة PNG واحدة، وفّر **مجلد** فيه ماسك لكل فريم
   (`00000.png, 00001.png, ...`). ProPainter بيقبل مجلد ماسكات بنفس عدد
   الفريمات. تقدر تولّدها بتتبّع (tracking) للّوغو — مثلاً بأدوات زي
   `CoTracker` أو تتبّع يدوي في After Effects ثم تصدير الماسك.

2. **لو اللوغو بيتحرك في نطاق محدود**: ارسم مستطيل أكبر يغطّي كل المساحة
   اللي بيتحرك فيها اللوغو (ماسك ثابت أوسع). أبسط، بس بيشيل مساحة أكبر.

---

## 4) نصائح للجودة

- خلّي الماسك **أكبر شوية** من اللوغو (هامش أمان) — `--dilate` في `make_mask.py`
  أو `--mask_dilation` في `remove_logo.py`.
- لو ظهرت رعشة خفيفة مع `delogo`، انتقل لـ `propainter`.
- لو الناتج فيه "تلطيخ" حوالين الحواف، صغّر الماسك شوية أو زوّد الـ dilation
  بحذر وجرّب.
- الخلفية كل ما كانت أبسط (سما/بحر)، كل ما كانت النتيجة أنضف.
